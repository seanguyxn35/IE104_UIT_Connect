# database/

Lược đồ và dữ liệu của CSDL UIT Connect (Microsoft SQL Server 2017 trở lên).

```
database/
├── schema.sql      # tạo bảng, khóa, ràng buộc
├── migrations/     # các thay đổi lược đồ theo thời gian (khi có backend)
└── seeds/          # dữ liệu mẫu cho prototype / kiểm thử
```

Yêu cầu nghiệp vụ dùng để thiết kế lược đồ: [docs/datab.pdf](../docs/datab.pdf).
